# Entry 10: Post-processing. The pipeline gets a darkroom.

## What happened

Step 7 is complete. A framebuffer now captures the composited diffuse+shadow output as a texture, and a new post shader applies four effects in sequence: bloom, Reinhard tone mapping, color grade, vignette, film grain.

The visual change is total. Grey WebGL demo → atmospheric horror. The cold blue-white light, the purple-black shadow depth, the film grain on top: the pipeline now has a mood.

---

## What was built

Three new additions: `post.vert`, `post.frag`, and a framebuffer in `main.js`. Plus one change to `sobel.frag` to add color to the light.

---

### Why a framebuffer

The post shader needs to READ the composited image (diffuse × shadow). You cannot read a texture you are currently writing to. So passes 1+2 had to be redirected into an off-screen buffer first.

```
[sobel pass]   ─┐
                 ├─→ framebuffer (fb) → [post pass] → screen
[shadow pass]  ─┘
```

`fb.begin()` / `fb.end()` wraps the first two passes. The result is stored in `fb.color`, a texture the post shader reads via `uScene`.

### `src/shaders/post.frag`

```glsl
#ifdef GL_ES
precision highp float;
#endif

varying vec2 vTexCoord;
uniform sampler2D uScene;
uniform vec2 uResolution;
uniform float uTime;

void main() {
  vec2 uv = vTexCoord;
  vec2 texel = 1.0 / uResolution;

  vec3 base = texture2D(uScene, uv).rgb;

  vec3 bloom = vec3(0.0);
  float spread = 3.0;
  for (int x = -1; x <= 1; x++) {
    for (int y = -1; y <= 1; y++) {
      vec2 offset = vec2(float(x), float(y)) * texel * spread;
      vec3 s = texture2D(uScene, uv + offset).rgb;
      bloom += max(s - 0.3, 0.0);
    }
  }
  bloom /= 9.0;

  vec3 color = base * 1.8 + bloom * 0.8;

  color = color / (1.0 + color);

  color = mix(vec3(0.04, 0.03, 0.10), color, clamp(color * 1.5, 0.0, 1.0));

  float vignette = 1.0 - smoothstep(0.4, 0.85, length(uv - 0.5));
  color *= vignette;

  float grain = fract(sin(dot(uv + fract(uTime * 0.01), vec2(12.9898, 78.233))) * 43758.5453);
  color += (grain - 0.5) * 0.06;

  gl_FragColor = vec4(color, 1.0);
}
```

This one change shifts the entire scene from neutral grey to institutional cold: fluorescent, clinical, wrong. The choice was deliberate: this is the light of a place that should not be inhabited.

### `main.js`, framebuffer added

```javascript
let myShader;
let shadowShader;
let postShader;
let heightMap;
let fb;

function preload() {
  myShader = loadShader('shaders/sobel.vert', 'shaders/sobel.frag');
  shadowShader = loadShader('shaders/shadow.vert', 'shaders/shadow.frag');
  postShader = loadShader('shaders/post.vert', 'shaders/post.frag');
}

function setup() {
  createCanvas(960, 540, WEBGL);
  noStroke();
  heightMap = buildHeightMap();
  fb = createFramebuffer({ width: 960, height: 540 });
}

function draw() {
  fb.begin();
  background(0);

  shader(myShader);
  myShader.setUniform('uResolution', [width, height]);
  myShader.setUniform('uHeightMap', heightMap);
  myShader.setUniform('uMouse', [mouseX / width, mouseY / height]);
  plane(width, height);

  blendMode(MULTIPLY);
  shader(shadowShader);
  shadowShader.setUniform('uResolution', [width, height]);
  shadowShader.setUniform('uLight', [mouseX / width, mouseY / height]);
  shadowShader.setUniform('uCharlie', [0.5, 0.5]);
  plane(width, height);
  blendMode(BLEND);

  fb.end();

  shader(postShader);
  postShader.setUniform('uScene', fb.color);
  postShader.setUniform('uResolution', [width, height]);
  postShader.setUniform('uTime', frameCount);
  plane(width, height);
}
```

## The math: where each effect comes from

### Bloom: 9-tap threshold extraction

```glsl
bloom += max(s - 0.3, 0.0);
```

For each of 9 neighboring pixels (3×3 grid, 3-pixel spread), sample the scene texture and subtract a threshold (0.3). `max(..., 0.0)` clamps the result: only pixels brighter than the threshold contribute to bloom. Average the 9 samples, add back to the base at 80% strength.

The `spread = 3.0` multiplier widens the sample offset. More spread = bloom halos spread further.

This is a single-pass approximation. A full Gaussian bloom uses multiple passes at different radii. For this project's scale, the 9-tap version is sufficient and defensible.

### Exposure boost

```glsl
vec3 color = base * 1.8 + bloom * 0.8;
```

The diffuse shader outputs values in the 0.08–0.7 range, mostly dark. Multiplying by 1.8 before Reinhard brings the lit areas into a readable range without clipping. The factor 1.8 is the exposure stop.

### Reinhard tone mapping

```glsl
color = color / (1.0 + color);
```

From [2] Reinhard et al. (2002). Compresses any HDR value above 1.0 (created by the exposure boost + bloom) back into [0, 1] range. Applied per channel. The curve: at color = 0 → output = 0. At color = 1 → output = 0.5. At color = ∞ → output approaches 1.0. Bright values compress toward white without hard clipping.

### Color grade: shadow tint

```glsl
color = mix(vec3(0.04, 0.03, 0.10), color, clamp(color * 1.5, 0.0, 1.0));
```

`mix(a, b, t)` interpolates between `a` and `b` by factor `t`. Here:
- When `color` is near zero (deep shadow): output ≈ `vec3(0.04, 0.03, 0.10)`, deep blue-purple
- When `color` is bright (lit surface): `color * 1.5` clamps to 1.0 fast, so output ≈ `color` unchanged

This lifts shadows away from pure black and pushes them toward a cold purple. Pure black contains no information, but these shadows do. The choice of `(0.04, 0.03, 0.10)` was deliberate: more blue than red, slight purple cast, dark but not void.

### Vignette

```glsl
float vignette = 1.0 - smoothstep(0.4, 0.85, length(uv - 0.5));
```

`length(uv - 0.5)` = distance from the center of the screen. `smoothstep(0.4, 0.85, ...)` maps that distance to [0, 1] smoothly. Subtracting from 1.0 inverts it: center is bright, edges are dark. The effect is photographic lens falloff: the peripheral world recedes into shadow, drawing focus to whatever is at the center of the scene.

### Film grain: hash-based noise

```glsl
float grain = fract(sin(dot(uv + fract(uTime * 0.01), vec2(12.9898, 78.233))) * 43758.5453);
color += (grain - 0.5) * 0.06;
```

A pseudo-random hash function. `dot(uv, vec2(12.9898, 78.233))` projects 2D UV coordinates onto a line using irrational constants, chosen because their decimal expansions produce maximally uncorrelated values for neighboring pixels. `sin(...)` folds the result into a bounded range. `fract(... * 43758.5453)` extracts the fractional part: near-uniform distribution in [0, 1].

`uTime * 0.01` shifts the input every frame so the grain pattern changes. `fract()` of a slowly-increasing time value prevents the shift from overflowing to visible patterns.

Adding `(grain - 0.5) * 0.06` centers the noise at zero and applies it at 6% strength, enough to read as film texture without dominating the image. Added last, after tone mapping, so it sits perceptually on top of the rendered image rather than being tone-mapped along with it.

No texture lookup. The randomness is computed entirely from the fragment's UV position and time.

## What the scene looks like now, and why it reads as horror

The cold blue-white light (`vec3(0.72, 0.83, 1.0)`) reads as institutional: the kind of light in places that should not be occupied. The shadow is blue-black rather than void-black, so it has depth and color. The smooth radial height map, under this light and color grade, now reads as a floor plane with something standing on it in the dark.

The shadow shape from Charlie Chat (the long dark wedge with a soft penumbra) is the entity. It doesn't need a sprite.

The bloom is subtle. The grain is subtle. The vignette is there without announcing itself. None of the effects are visible as effects. They combine into a mood.

---

## Order matters

The effects must run in this sequence:

1. Sample base + compute bloom (before tone mapping: bloom should be in linear light)
2. Reinhard tone mapping (compress HDR back to [0, 1])
3. Color grade (applied after tone mapping so shadow tint doesn't compress)
4. Vignette (darkens edges of the tone-mapped, graded image)
5. Film grain (added last: sits on top perceptually, not tone-mapped)

Running grain before Reinhard would tone-map the noise along with the scene: the grain would compress in the highlights and look wrong.
